LOCAL QQ MUSIC

本机 QQ 模式教程

在安装了 QQ 音乐的 Windows 电脑上，使用浏览器转换 MFLAC 和 MGG。

先解决：QQ 音乐已启动，却提示无法附加

unable to access process … from the current user account 表示服务没有访问 QQ 音乐进程的权限。常见原因是运行账号或权限级别不同，或服务启动在受限环境中。

  1. 先下载其他已完成任务的结果，然后到启动旧服务的终端按 Ctrl+C，等待旧服务退出。关闭网页标签不会停止服务。
  2. 在项目目录找到 start_local_qq.bat，右键选择“以管理员身份运行”，由你确认 Windows 权限提示。使用与 QQ 音乐相同的 Windows 用户。
  3. 保持新终端窗口打开，在地址栏打开 http://127.0.0.1:8766，确认显示“本机 QQ 模式”。
  4. 重新上传原始文件，再点击开始转换。服务重启后，旧任务不再保留。

只刷新网页、更新 Cookie 或以管理员身份打开浏览器，都不会改变 Python 服务的进程权限。如果希望用普通权限运行，可先彻底退出 QQ 音乐，再将 QQ 音乐与服务都以普通权限启动。

第一次使用：准备运行环境

  1. 安装 Python 3.10 或更高版本；在项目文件夹打开终端。
  2. 安装网页和 QQ 解密依赖：
    python -m pip install -r requirements-web.txt -r requirements.txt
  3. 确认 FFmpeg 在 PATH 中，或保留已有的 input/Tools/ff.exe。MGG 还需要 qmdec：
    python -m pip install git+https://github.com/Sophomoresty/qmdec.git
    此命令需要 Git；已有 input/Tools/qmdec/src 的工程可直接使用该源码。
  4. 启动 Windows 桌面版 QQ 音乐，并登录你有权限访问这些文件的账号。

日常使用：启动、转换、下载

  1. 双击 start_local_qq.bat。若出现上述权限错误，再按第一节的方法以管理员身份启动。脚本优先使用项目的 .venv，否则使用 PATH 中的 Python。
  2. 浏览器访问 http://127.0.0.1:8766，点击右上角“检查环境”。可用选项表示依赖与进程被检测到，不代表已验证附加权限或所有文件版本。
  3. MFLAC → FLAC：添加 MFLAC 文件并勾选对应任务，直接开始转换。此流程依赖 QQ 音乐进程，不通过更新 Cookie 修复权限问题。
  4. MGG → MP3：先点击“更新 Cookie”，成功后添加 MGG 并开始转换。需要有效 Cookie 或密钥缓存，且取决于文件版本。
  5. 完成后试听，下载单个文件或 ZIP。若网页已有上一批任务，先下载结果并点击“删除任务与文件”，再开始下一批。

使用完成后，在服务终端按 Ctrl+C 停止。脚本的临时任务保存在 .web-data-qq；结果会过期，不要将它当作音乐收藏目录。

手动启动与常见问题

也可在项目目录的独立 Windows PowerShell 中运行：

python run_web.py --local-qq --host 127.0.0.1 --port 8766
  • 网页仍显示通用转换模式：检查地址是否为 8766，以及启动参数是否包含 --local-qq；不是原来的 8765 通用服务。
  • 端口已占用：在原终端停止旧服务，或使用其他端口启动，并在浏览器打开相同端口。不要结束不认识的进程。
  • 管理员启动后找不到依赖：可能用了另一个 Windows 用户或 Python。优先使用项目 .venv，用同一个解释器安装依赖和启动服务。
  • 权限匹配后仍失败：用独立 PowerShell 启动，检查是否存在进程访问限制；无需关闭安全软件。若错误变为 hook 加载失败，需检查 QQ 音乐客户端版本是否兼容，并保留详细日志排查。

本机模式仅允许这台 Windows 电脑访问。公网网站、Docker 或手机上的网页不能直接附加你电脑中的 QQ 音乐；网页按钮也不能自动提升 Windows 权限。
